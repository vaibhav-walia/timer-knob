Timer Knob Support

Need help or found a bug? Email timerknob.support@gmail.com.

Set a time

Turn the knob. It snaps to each minute, and one full turn is 60 minutes, up to 3 hours. To type a time instead, tap the time on screen.

Start the timer

Press the knob. It stays pushed in and locked while the timer runs.

Stop the timer early

Tap Reset. It's the only way to stop a running timer, and it clears the time to 0:00.

When time's up

Press the knob once to silence the alarm and wind back to the same time, then press again to run it again.

No sound

Timer Knob follows your iPhone's silent switch, so turn silent mode off and check your volume. Haptics still work in silent mode.

No notification when time's up

Go to Settings > Notifications > Timer Knob and turn on Allow Notifications. Check that a Focus mode isn't silencing them.
